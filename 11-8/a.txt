If you want to stay as close to SemDINO as possible, I would actually avoid object detection altogether.

The paper's core claim is:

DINOv3 provides dense semantic representations of land-cover classes (building, water, vegetation, bare soil, etc.), which are fused with CNN features and then aligned across time.

So before change detection, the most faithful intermediate demonstration is:

Demo: Semantic Land-Cover Discovery using DINOv3

Pipeline:

Remote Sensing Image
        ↓
 Frozen DINOv3
        ↓
 Patch Features
        ↓
 PyFu-style Adaptation
        ↓
 Pixel/Patch Classification
        ↓
 Land-Cover Map


Output visualization:

Building      = Red
Vegetation    = Green
Water         = Blue
Road          = Gray
Bare Soil     = Yellow


This is almost exactly what SemDINO needs before temporal alignment.

Strong Demo #1 (Closest to Paper)

Use a pretrained DINOv3 backbone.

Extract patch tokens:

features = dinov3(image)


Cluster them:

KMeans(n_clusters=5)


Produce:

Original Image
Semantic Region Map


Then explain:

"These are the semantic priors used by SemDINO before cross-temporal alignment."

This is extremely aligned with the paper.
